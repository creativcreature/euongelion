# Bible-in-a-Year — 365-Day Content Calendar (2026)

**Purpose:** A canonical-chronological reading + reflection plan that
the founder can hop into on any day and gain self-contained insight.
Each day is a stand-alone devotional (single-day chiastic A-B-C-B'-A'
arc per `.claude/skills/euangelion-platform/references/content-structure.md`),
600–900 words, BSB scripture, with Christ-connection + meta-story
placement.

**Used by:**
- Homepage "Today's Devotional" surface (computes day-of-year against
  this calendar)
- `/series/bible-365` calendar page (browse by month, hop to any day)
- `src/data/bible-365.ts` SeriesInfo (slug pattern: `bible-365-day-N`)

**Voice + writing rules:** see `docs/AI-CONTENT-CONSTRAINTS.md`,
`docs/PUBLIC-FACING-LANGUAGE.md`, and `.claude/agents/DEVOTIONAL-WRITER.md`.

---

## Year Arc

| Quarter | Weeks | Focus |
| --- | --- | --- |
| **Q1 (Jan-Mar)** | 1-13  | **Foundations**: Creation → Patriarchs → Exodus → Wilderness → Conquest |
| **Q2 (Apr-Jun)** | 14-26 | **Kingdom**: Judges → Samuel/Saul → David → Solomon → Divided Kingdom → Exile |
| **Q3 (Jul-Sep)** | 27-39 | **Promise**: Prophets → Wisdom → Return → Intertestamental hope |
| **Q4 (Oct-Dec)** | 40-52 | **Fulfillment**: Gospels → Acts → Epistles → Revelation |

**Weekly rhythm:** 5 reading days + 1 deeper-dive day + 1 sabbath/reflection day.

**Topic coverage** (each appears at least once across 52 weeks):
identity, peace, suffering, doubt, hope, justice, prayer, scripture,
worship, community, sin/repentance, grace, sanctification, witness,
sabbath rest, vocation, money, sexuality, marriage, parenting,
death/grief, eschatology, mystery, election, holiness. Christ-connection
required in every week.

## Generation note

The full table for Q2-Q4 (weeks 14-52, days 92-365) is intentionally
abbreviated above. **`scripts/generate-bible-365-stubs.mjs`** (created
in Stage 2 of this plan) reads the canonical sweep + per-week book
breakdowns AND the chiastic week pattern (Day1 hook · Day3 pivot ·
Day5 application · Day6 deeper · Day7 sabbath) to emit:

1. 365 placeholder devotional JSONs at `public/devotionals/bible-365-day-N.json`
2. The `bible-365` SeriesInfo entry in `src/data/bible-365.ts` with
   all 365 day stubs (slug + title + day number + scripture reference)
3. A "draft in progress — try Day {today's day-of-year} for today's
   reading" UX message for any day not yet hand-drafted

Days 1-7 will be hand-drafted via the devotional-writer agent in
Stage 2 of the plan. The remaining 358 days fill in over time via
batched writer runs (documented in `docs/runbooks/bible-365-writing-pipeline.md`
which Stage 2 also creates).
