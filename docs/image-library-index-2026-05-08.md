## How to use this index

Each surface section below lists every canonical filename + theme keywords +
how many regional/run variants exist. To **mark a file as skip** (English overlay,
off-brand, etc.), add a leading `~~` to its row (markdown strikethrough). The
mapping scripts (Stage 2 + Stage 3) honor `~~` rows by excluding them from
candidate selection.

To **prefer a non-canonical variant**, look up the file in the catalog JSON and
re-copy from `variants[N].sourceRel` to `public/images/site/<surface>/<filename>`.
