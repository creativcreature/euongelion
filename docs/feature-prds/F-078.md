## Problem

The SA-026 gate returns typed 401/402 codes with no surface to answer
them: no paywall, no held-generation resume, no checkout return states,
no success room, no subscription management. Payments infrastructure
existed but had zero user-facing presentation.

## User Expectation

- The paywall is a continuation of my reveal — my own words echoed, my
  requested edition held and resumed automatically after sign-in or
  purchase, with zero re-typing.
- Honest commerce: the true billed amount beside every button, a
  lifecycle timeline instead of fine print, a first-class decline, and
  one-tap cancel with everything I generated staying mine.

## 10/10 Definition

- Paywall States A (free edition banner) / B (offer stack: Annual
  RECOMMENDED preselected, Monthly, More durations for 2yr/3yr) /
  allowance-exhausted / skeleton / price-failure / payments-off — each
  with a next action; covenant verbatim; SA-024 two bespoke
  presentations (mobile sheet + sticky summary footer; desktop
  editorial spread + specimen).
- Held selection (24h TTL, fresh-tab safe) resumes via
  `?resume=1` after sign-in and after checkout; re-gates if still
  unentitled.
- Return leg: pending (entitlements poll, paywall never re-shown),
  stalled-honesty, Guardian success room (single CTA resumes the held
  generation; Founding Member N of 500, never fabricated), cancelled
  ("No charge was made", request saved).
- Settings: Account subscription row + `/settings/subscription`
  management page — visible one-tap Cancel via portal, post-cancel
  "editions remain yours forever", one-time-term variant.

## Methodology References

- M00 (one primary CTA per state; errors end in an action); pattern doc
  §1–§2 with Mobbin citations; SA-024/SA-025/SA-026/SA-027.

## Device Contracts

### Desktop

- Editorial two-column paywall spread (offer stack left, specimen +
  lifecycle timeline right) in the masthead frame; management page in
  settings layout; success room as a centered editorial card.

### Mobile

- Full-height paywall sheet over results context, sticky footer with
  true-amount summary + single CTA, radio cards ≥44px, safe-area aware
  above the tab bar; management as a pushed settings page.
