## Problem

Founder, 2026-08-19 morning, verbatim: the feature devotional lacked a series
link; the games were still clustered; the crossword sat beside a huge blank
area; "You didnt add any modules"; the cartoon had no placeholder; the
practice/word boxes were cramped; "Week after Pentecost" was arbitrary and
unexplained; the returning-reader band destroyed the flow; a word search was
wanted; "MORE CONTENT! MORE SECTIONS! MORE MODULES YOU HALF ASSED IT!"

The root cause of "no modules": the seven new kinds shipped as DB rows behind
a SQL paste that never ran. Content that is deterministic never needed a
database round-trip.

## Solution

**The architectural correction.** Deterministic modules now compute PAGE-SIDE
at render time from data bundled into the worker (`src/lib/edition/
page-modules.ts` + Workers-safe generators through `getVerse`'s ASSETS path).
No rows, no paste, full paper by construction. The DB keeps what it is for:
the review queue (lead, practice, strip, screening) and the audited gallery.

**The desktop spread, recomposed and interleaved** (~30 modules): practice +
word (opened up) → quiz 1 · red letters · Bible-in-a-year (thirds) →
crossword with the Catechism Corner beside it (the blank is content now) →
the funnies' reserved frame beside the elaborate season → the 7-plate gallery
→ the verse-rebuilt beside the archive pull → guides → the word search beside
quiz 2 → the hymnal → memory verse · the question · quiz 3 (thirds) → the
daily prayer beside a historic voice → reported sections when present.

**New standing content, all honest:**

- _The Catechism Corner_ — Heidelberg Catechism (1563, public domain),
  printed as the catechism gives it.
- _The Hymnal_ — public-domain hymns (≤1928), verbatim received text only;
  anything uncertain was dropped, not paraphrased.
- _Voices_ — 200 verbatim attributed quotes extracted from the reference
  corpus by a script that attributes from each file's own title header,
  excludes the corpus's mislabeled Gutenberg bundles (a "spurgeon" file
  containing Willa Cather fiction), and asserts every quote is a substring
  of its verified source.
- _The Season, elaborate_ — every season and feast liturgical.ts can emit
  gets a color band, plain name, span, real essay, and the numbered week
  explained through the season's own pattern. "Week after Pentecost" never
  appears bare again.
- _The Word Search_ — 45 themed sets, deterministic 12×12, 8-direction
  placement, drag-to-find client.

**The critique, point by point:** lead links its full series; the
returning-reader card is a side panel at the top of the rail; compartments
gained internal air; the funnies has a designed reserved frame (the gallery
is not the cartoon and never was); quiz split across three positions; games
never adjacent.

## Platform Contracts

### Desktop

- Thirds rows (`paper-box--third`) carry quiz singles, red letters, B365,
  memory verse, question; two-and-one rows pair every interactive with prose.
- The season band is a 6px stripe in the season's liturgical color.

### Mobile

- All rows collapse single-column in DOM order (games stay separated);
  word-search cells keep ≥44px effective hit areas; nothing scrolls the page
  horizontally.
