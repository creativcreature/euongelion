## Problem

Global chrome is a per-page newspaper masthead (`EuangelionShellHeader`) with hamburger-only mobile nav and no bottom tab bar. The two returning-user surfaces (Daily Bread, Library) are demoted into the avatar menu/footer. On mobile the product reads as a responsive website, not an app — the single biggest blocker to gallery-grade IA (audit Part 6: Navigation C+).

## Decision (SA-024, founder-locked)

One data layer, two bespoke presentations. Mobile: persistent safe-area-aware bottom tab bar with destinations Today · Series · Soul Audit · Library · You; mobile top bar carries identity + utilities ONLY (wordmark/date, search, active-plan resume glyph, theme toggle, account) — zero duplication with the tab bar. Desktop: the editorial masthead keeps horizontal destinations (HOME · TODAY · SOUL AUDIT · SERIES · DAILY BREAD · LIBRARY · HOW WE WRITE) with utilities right-aligned — Daily Bread + Library return to primary nav.

Real-world anchors: Open (dark minimal 4-tab), Calm (Home/Sleep/Discover/Profile), Headspace (Today/Explore/[Name]).

## 10/10 Definition

- Tab bar persistent on all primary app surfaces on mobile; may hide inside the immersive reader.
- Safe-area-aware (`env(safe-area-inset-bottom)`), touch targets ≥ 44px, active state clear in light + dark.
- Zero destination duplication between mobile top bar and tab bar.
- Desktop masthead reaches Daily Bread + Library in ≤ 1 click.
- Verified at 375 / 390 / 768 / 1280 / 1440, light + dark.
- Reconciled with docs/decisions/APP-VS-WEB-APP.md and docs/methodology/M04.
