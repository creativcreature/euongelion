## Problem

Reminders are thin, config-gated, with no scheduler — a local-only toggle that doesn't do what it says. Web push sending exists (send-daily-push edge fn) but no user-facing schedule.

## 10/10 Definition

- Single time-window picker in brand voice ("one quiet word each morning") wired to real scheduled delivery (web push).
- Honest states: permission denied, unsupported browser — designed, not silent.
- Waking Up "Moment" as anchor.
