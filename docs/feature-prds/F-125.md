### 07 · Contrast on the two highest-stakes controls

| Control         | Was        | Cause                                                              | Now                                     |

### 64 · The founding-member track was invisible

`rgba(247, 243, 237, 0.08)` — a cream at 8%, assuming a dark ground. On the

### 65 · Homepage CTA raised to a 44px target

### 02 · The reader's heading ladder

- `CuratedActiveView` rendered its own `h1` **and** `DevotionalHeadline`'s `h1`
  in the same path (the earlier `return` at :218 is an error branch, not an
  alternative). The series title drops to `h2`; the reading keeps the `h1`.
- Eight section labels on `/today` (`SCRIPTURE`, `REFLECT`, `PRAYER`,
  `OPENING`, and the Sabbath screen's `Rest`) were styled `<p>`s — invisible to
  heading navigation. Now `h2`/`h1`.
- Module headings sat at `h3` directly under the reading's `h1`, skipping a
  level on 519 of 530 devotionals: `TeachingModule`, `ReflectionModule`,
  `ProfileModule`, `RecapModule` now emit `h2`.
- `TeachingModule` mapped markdown `##` to `<h2>` _inside_ that heading's own
  section — subordinate prose outranking its parent. The map shifts down one:
  `##`→`h3`, `###`→`h4`.

Tailwind v4 preflight zeroes heading margin, size and weight, so every one of
these tag swaps is visually inert; the classes carry the type.

### 03 · The 37 series titles are headings

They were inert `<span>`s, so a screen-reader user had nothing to jump between
on the flagship browse page. All eight title classes across Covers, Preview,
Issues, Feature, Rack, Spines and List emit `h3`; the Feature view's desk name
moves up to `h2`.

Two CSS rules neutralise the UA heading defaults that would otherwise change the
design — every one of those classes already owns its `font-size`.
`.rack-masthead` is excluded from the margin reset and `.stock-title` from the
weight reset, because each already declares that property.

### 60 · The artwork is credited, and stops reading as a filename

Founder: _"artist is Christopher James Parker + Ai"_, then _"add Christopher
James Parker + AI, to God be the Glory"_.

350 entries carried `artist: 'Generated'`. All now credit
**Christopher James Parker + AI, to God be the Glory**.

Separately, those same entries carry a title that is the source filename
title-cased — "Sym Doorway Arched Linocut". Interpolated into `alt` that
announces as a filename read aloud. `src/lib/artwork-alt.ts` detects the
machine-title pattern; where it matches, the image takes `alt=""` because the
visible `<figcaption>` beside it already carries the title and the credit, so a
screen reader hears it once rather than twice. Hand-written titles — the
Rembrandts, Vermeers and the rest — keep their descriptive alt.

### 57 · The dead mobile-nav system is gone

`.mock-mobile-nav-panel` and five siblings, **zero usages in any `.tsx`**.
Thirteen rule blocks removed. This is why an earlier session concluded the menu
"had no styles": the styles existed under the _old_ class names and the
component had been renamed without porting them.

### 58 · `is-open` is applied rather than deleted

Three rules styled `.mock-mobile-menu-toggle.is-open`; the class was never
applied, so the toggle changed glyph but never state. The class is now bound to
`mobileMenuOpen`, which activates styling that was already designed for it.
