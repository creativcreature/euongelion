## Problem

Closing the loose ends from the 2026-08-16 brief, plus two defects found while
doing it.

## 1. Image generation is Codex built-in only

Founder ruling, now recorded in `CLAUDE.md`:

- Use **Codex's built-in `image_gen`** — covered by the ChatGPT subscription.
- **Never** `~/.codex/skills/.system/imagegen/scripts/image_gen.py`. It calls the
  OpenAI Images API and **bills the founder's API account per image**.
- **Nano Banana is banned** for this project, overriding the global cost-based
  default in `~/.claude/CLAUDE.md`.
- Higgsfield stays retired.

**Disclosure:** 8 images were generated through the billed CLI *before* that
ruling arrived. The founder accepted the spend.

**Claude Code cannot generate imagery for this project.** It has no built-in
`image_gen`, and there is no `codex` binary on PATH, so Codex cannot be driven as
a subprocess either. Image work belongs to the Codex session.

**The style anchor is the real variable.** Text-only prompts drift off-brand
regardless of generator — which is what made the first pass look wrong and
nearly got the generator blamed for it. The founder-approved anchors must be
attached as references on every generation.

Size ceiling (1536×1024 / 1086×1448) is expected; the never-upscale rule is
lifted for built-in runs, with upscaling done downstream by the founder.

## 2. Reveal must fail open

The home page shipped its three step cards **invisible**: they carried
`data-reveal`, the observer never fired for them, and they sat at `opacity: 0`.

Content hidden behind motion is strictly worse than no motion. Two guards, both
of which can only ever **reveal**:

1. anything already inside the viewport is revealed on mount
2. a sweep 2.5s after mount reveals anything still hidden

The worst case is now a missing animation, which is how this should degrade.

## 3. The mobile menu had no CSS at all

`.mock-mobile-secondary-nav` had **zero rules** — an unstyled block rendered
inside a sticky topbar, so it inherited the header's stacking, travelled with it,
and a long list had nowhere to go.

It is now a fixed panel anchored to the **viewport** (not the header, which can
leave the screen), at `z-index: 300`, scrolling inside itself with overscroll
containment, with full-width rows at a 2.9rem tap height.

## 4. Four pages drew the masthead twice

`SiteBottom` draws it, and `/today`, `/library`, `/series/[slug]` and
`/devotional/[slug]` each drew their own immediately after — introduced when
`SiteFooter` was swapped for `SiteBottom` in F-103. De-duplicated.

## 5. The masthead intro, and the shrinking wordmark

A cobalt curtain with the wordmark reversed out, lifting to reveal the page
already sitting underneath in the reader's own theme. Home only, once per
session, `pointer-events: none` and `aria-hidden` from the first frame so it can
never block a reader, skipped entirely under reduced motion. The page is never
hidden behind it — the overlay paints on top of a fully rendered document.

The wordmark also shrinks on scroll, driven by the nav's existing `is-docked`
state rather than a second scroll listener.

## 6 & 7

`/today` takes the paper's ruled compartments too, per the founder scoping the
Sea Harvest vocabulary to Today and Daily Bread only.

`/how-we-write` was untruthful **by omission** — it documented none of what had
shipped since. Added the red-letter method (KJV OSIS cross-referenced onto BSB
wording, never inferred from quotation marks) and the Audio Edition (synthetic
voice, said plainly; full text, not an abridgement).

## Platform Contracts

### Desktop

- Masthead intro fills the viewport, lifts after 900ms, never intercepts a click.
- Wordmark scales to 0.86 once the nav docks.
- `/today` blocks render as ruled compartments sharing edges.

### Mobile

- Menu panel is fixed to the viewport under the topbar, scrolls internally with
  `overscroll-behavior: contain`, rows at 2.9rem minimum tap height.
- Intro and wordmark shrink both respect `prefers-reduced-motion`.
- Compartments stack to one column, keeping their shared rules.
