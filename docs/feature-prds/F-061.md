### T2 fix-up — build-time teaser index (post-deploy)

The first T2 implementation used `fs.readFile(public/devotionals/${slug}.json)` from `generateMetadata`. That works locally and during prerender, but **silently failed in the Cloudflare Workers runtime** because `public/*` is bound as ASSETS, not present on the Worker filesystem. Production was serving the series-question fallback instead of the day teaser.

Fix: `scripts/generate-devotional-teasers.mjs` scans `public/devotionals/*.json` at build time and writes `src/data/devotional-teasers.ts` (a `Record<slug, teaser>` of all 534 day teasers). `generateMetadata` imports `getDevotionalTeaser(slug)` from that index — pure data lookup, runtime-agnostic. Wired into `npm run build` as a pre-step.

Files: `scripts/generate-devotional-teasers.mjs` (new), `src/data/devotional-teasers.ts` (generated), `src/app/devotional/[slug]/page.tsx`, `src/app/wake-up/devotional/[slug]/page.tsx`, `package.json` (build script).

Verified live at https://euangelion.app/devotional/peace-day-3 — description is now `"The pivot: Jesus offers a peace that doesn't depend on controlling chaos..."`.
