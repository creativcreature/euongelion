# F-096: Series imagery — region-accurate people, fully developed frames

## Metadata

- Feature ID: F-096
- Category: Imagery
- Owner: founder
- Status: shipped (2026-08-15)
- Decision: SA-052
- Surfaces: series cards, series page hero, devotional headline, OG cards

## Problem

The founder rejected the existing series imagery and the first regeneration
attempt. Three defects, each with a different cause:

1. **Cream paper border** — 17 of 21 first-pass masters. `sharp.trim()` could not
   remove it; the gradient is too soft to threshold.
2. **Whitewash** — _"these all look like generic ai white people and not region
   and hostory seocific people."_ The prompt never named a period, so the model
   defaulted to contemporary Western: a boy in a sweatshirt and jeans.
3. **Empty backgrounds** — _"no stark nothing backgrounds."_ Subjects floated on
   bare cream.

## Root causes

**The whitewash was a rendering problem, not only a wording problem.** In a
cobalt-on-cream duotone the cream paper is the only other ink, so _unprinted skin
is white skin_. Naming an ethnicity while leaving skin near paper still outputs a
white person. The fix states skin as a **value**: brown to deep brown, therefore
printed at dense dot coverage, obviously darker than the ground.

**The empty backgrounds were self-inflicted.** The old style block asked for
"generous negative space… small figure scale", which the model read as permission
to leave the frame blank. That line is deleted and replaced by a
FULLY DEVELOPED FRAME clause.

**The grain was upscaling.** `next.config.ts` sets `images.unoptimized`, so Next
serves the raw file with no srcset. The headline slot is `aspect-ratio: 1408/768`
at `sizes="(max-width:900px) 100vw, 66vw"` — about 1267 CSS px on a 1920 desktop.
A 1024 square was being upscaled ~1.24× in that slot, and upscaled Ben-Day dots
read as mush. Installed size is now 1600×872, the same shape as the slot.

## Verification gate

`scripts/imagery/verify-masters.mjs`. Steps 1–2 are measured; step 3 is not
attempted, because it cannot be:

1. Border — 3 samples down each edge of the 1408×768 crop must be ink.
2. Blank paper — bare-paper coverage across the frame < 2%.
3. **Figures — a human look.** Period dress, dense-dot brown skin, no
   blacked-out faces. A plate can clear 1 and 2 and still fail this.

Result: 33/33 measured pass. `rooted` failed on first run at 3.7% blank sky,
was regenerated with an explicit sky clause, and passed.

## Round 3 — the editorial pass (2026-08-16)

Founder rejected round 2 as uniform: _"all the images feel like they are
depicting the same devotional… very hard to tell what images are supposed to be
depicting as they all basically feel the same."_ Also asked for a New Yorker
register, retained surrealism, correct hands, and no typical-AI look.

### The cause was arithmetic, not taste

Round 2 derived all eight site ratios from one square master. The crop-safe
intersection of those ratios is the central **60% x 27% — 16% of the frame**, so
every composition was forced to the centre with padding around it. The pipeline
was mathematically producing the fault being complained about.

Replaced with two masters, each composed to its own shape:

| Master    | Size            | Safe zone | Serves                                                                 |
| --------- | --------------- | --------- | ---------------------------------------------------------------------- |
| Landscape | 2400x1600 (3:2) | ~50%      | heroes, cards, Rack, headline, artwork frames, bento lead/default/wide |
| Portrait  | 1800x2400 (3:4) | ~60%      | Covers, Mosaic, tall Mosaic, rhythm block, bento tall                  |

Homepage `3358/920` is not series art. Social and OG are out of scope.

### Results

```
                 mean ink   sd     range
round 2 (rejected)  78%     9.7    55-99%
round 3             53%    26.8     7-100%
approved four        —       —     22-85%
```

### Clauses that produced it

- **COVERAGE DISCIPLINE** — the stated ink percentage is a hard budget; render the subject and stop. Band accuracy went 0/4 → 4/8 on first contact.
- **SCALE MUST BE LEGIBLE** — an object alone on a plain reads as ordinary, not giant. Explicitly permits the one figure that supplies scale, which the "no background figures" rule had been killing.
- **HANDS AND ANATOMY** — five fingers, real joints, prefer hands doing physical work; obscure them when they are not the subject.
- **NOT AI ARTWORK** — names the tells (airbrushed haze, uniform detail, bilateral symmetry, filigree, plastic sheen) and the alternative (uneven ink, deliberately flat passages, one light direction).

### The gate was wrong twice, in the same direction

It measured blankness by **lightness**, so every correct cream-dominant AIRY
plate failed. And it sampled after a downscale that averaged the halftone away,
so printed texture read as flat. It now measures local variance **at native
resolution**: printed quiet has dot texture, blank paper does not. 32/33 pass;
the single flag is the same lightness artifact on a pale edge, confirmed printed
by variance 128.6 against a flat-threshold of 6.

**Generator note:** a four-plate head-to-head found Codex's own run better
calibrated (1/4 vs 0/4 in band) but smaller at 1536x1024. Founder chose
Higgsfield after seeing the comparison. Codex's set is preserved at
`imagery-staging/series-v2/landscape/` for inline devotional use.

"If in doubt, make it plainer"                                            |

### The gate's second false-negative class

Its border check was **lightness-based**, so both airy replacements failed it for
having pale edges — the same error class that nearly cost nine good plates. An
edge now counts as a border defect only if it is pale **and flat**: a real print
border is unprinted, an airy composition is not. Proven still-sensitive against a
synthetic flat-border plate, correctly rejected `BAD(6/6)`. 33/33 pass.

**Standing lesson:** every automated check here has failed in the same direction —
treating _light_ as _absent_. Anything measuring "is this region empty" must
measure texture, at native resolution, never brightness.

## Readability standard (SA-053, 2026-08-16)

Founder: _"It feels slightly too mature for some audiences… 8th grade level reading
maybe slightly more elevated… I want the breadth of content to stay the same, but
slightly lower reading level."_ Then: _"I dont want any retro active changes to
text- just to the skill for future devotionals."_

**Measured before changing anything, and the measurement overturned the premise.**
Authored prose only, quoted Scripture excluded:

```
                          FK    Ease  w/sent   30w+   45w+ sentences
looking-at-the-sun       6.7      75    15.5  11.6%        11
he-cannot-deny-himself   7.9      70    17.4  14.5%        25
the-harvest              8.4      68    18.7  17.1%        23
prayer-of-jabez          8.0      69    17.2  12.6%        17
weighted                 7.7      71    17.4  15.3%
```

The average is already 8th grade; Reading Ease 71 is plain English. The density is
in the **tail** — 45–95 word sentences scoring grade 33–36 that an average cannot
see. So the gate is the tail: **FK ≤ 8.5, under 8% at 30+ words, nothing over 45.**

**36% of the over-30-word sentences share one shape:** setup clause + embedded
archaic quotation + continuation, punctuated as one sentence. Setup sentence, quote
its own sentence, response sentence. `story` (20.9 w/sent) and `insight` (24.3) are
the offenders against `teaching` (16.6).

**Fix by re-punctuation, never deletion** — splitting at existing clause boundaries
moves FK 7.7 → 7.2 and 30w+ from 15% → 11% without cutting a word.

The chiastic arc survives with a lower ceiling: **8th → 10th → 11th → 10th → 8th**,
down from "12th → college". A flat cap would have destroyed the pivot-day design,
so it was raised with the founder before changing rather than after.

**Forward-only. No devotional text was modified.** Tooling:
`scripts/check-readability.mjs`, run at the Phase 5 editorial gate.
