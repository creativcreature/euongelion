# F-156: Audio is reachable from every page

## Metadata

- Feature ID: F-156
- Category: Reading surfaces
- Owner: founder
- Status: wip
- Decision: SA-110
- Surfaces: `EuangelionShellHeader` (27 pages), `src/components/audio/AudioHeaderButton.tsx`

## Problem

Founder, immediately after the sidebar shipped:

> "wait I should be able to access the audio player on everypage right?"

He could not, and the regression was mine. SA-109 moved discovery off `/series`
and into the sidebar — correct — but the sidebar could only be opened by the
tucked handle, and the handle requires something already queued
(`!!item && started`). So with an empty queue the **entire site had one entry
point: the homepage callout.** On `/series`, `/today`, `/daily-bread` or any
devotional there was no way to reach audio at all.

This is the failure mode of removing an intrusion without replacing its
function. The picker was in the wrong place; it was also, at that moment, the
only way in.

## Solution

**An audio control in the masthead utilities tier**, beside search and theme.
That tier is right for three reasons: it renders on all 27 shell pages, it costs
no vertical space and interrupts no reading, and it is where the site already
puts global utilities (SA-024 put search there rather than in the mobile tab
bar — the same argument applies).

Present on both the desktop utilities row and the mobile topbar row.

**A dot marks a live queue.** It appears only when something is actually queued,
pulses only while playing, and stops entirely under `prefers-reduced-motion`.
That is the "not invisible" requirement met without the control ever being loud:
quiet when there is nothing to return to, legible the moment there is.

It is positioned absolutely rather than drawn with a pseudo-element, because
`EditorialMotionSystem` claims `::after` on `.mock-paper` controls at runtime and
any `::after` geometry there un-collapses a hidden underline into a painted slab.

## Platform Contracts

### Desktop

- Sits first in `.mock-topbar-utilities`, before search.
- Inherits `.mock-icon-control` sizing, so it matches its neighbours exactly.

### Mobile

- Rendered in `.mock-topbar-mobile-row` beside the mode toggle.
- Inherits the same control size and target as the toggle it sits next to.

## Acceptance

- [x] Opens the sidebar with an empty queue, from any shell page.
- [x] No dot when nothing is queued.
- [x] Dot present, and the count announced, when a queue exists.
- [x] Pulse respects `prefers-reduced-motion`.
- [x] Present on both desktop and mobile rows.
