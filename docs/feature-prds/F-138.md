## Problem

Founder, 2026-08-19 (pinned in FOUNDER-ACTIONS.md, eleven items): the verse
unscramble overflowed the page; footer pages described a site that no longer
exists; typographic hierarchy was "allover the place"; the prayer lacked
biblical annotation; the guides felt incomplete; the gallery deserved Vasari;
the paper needed ~30 modules with the games broken up; the reading needed
audio (Voicebox only); and the page itself should be "an exceptionally
AWWWORTHY landing page… in the style we already have, but pushed."

## Solution

**Scroll choreography, native and restrained.** Research first (last30days +
Mobbin): the community's turn is away from scroll-hijack toward motion that
serves reading; CSS `animation-timeline` runs compositor-side at ~85% support.
So `design-system/edition-scroll-motion.css` ships four devices — a cobalt
reading spine that fills as you read, section rules that draw themselves,
plates that settle a breath as they arrive, a masthead that folds from
broadsheet to reading size — all inside `@supports (animation-timeline)` and
`prefers-reduced-motion`, zero JS added, F-104's reveals untouched.

**The paper reads as a paper.** A contents line under the masthead jumps to
any section. The unified type ladder (design-system/TYPE-SCALE.md): ten rungs,
66 stray declarations migrated, 11 heads assigned to rungs. The unscramble is
contained; every compartment carries the container rule.

**The Gallery is a spread.** Seven plates a day from the audited pool, lead
plate plus a six-thumb contact row, a lightbox that pages all seven with the
full Vasari entry — 145 entries, each written by an agent LOOKING at the
print: a title from the image, what is literally in the frame, and one line
of honest connoisseurship. Vasari register stays strictly on art captions.

**The prayer carries its verses.** Superscript verse numbers straight from the
corpus, Psalm reference singular.

**The guides grew up.** Six essay pages (`/guides/[slug]`, 500+ words each,
documented history only — Guigo II is cited, nothing else is claimed),
expanded steps, honest mistakes, go-deeper passages; the Daily Bread cards
link through.

**The byline has faces.** `/authors/milo` (honest: the pen name for the AI
synthesis, arranged and reviewed by human editors) and `/authors/james-parker`
(the editor), with author marks from audited prints — no fabricated photos.

**Every footer page tells the truth.** A claim-by-claim audit against the
code fixed /how-we-write (storage claims, audio overstatement, the byline
story, the Daily Bread's computed-vs-reviewed split), /help, /about, /credits,
/pricing, translations, and the legal set.

**The reading speaks.** Fifteen rotation slugs (provision/truth/hope) had no
audio because the pipeline never supported panels format. The Python extractor
now mirrors `buildPanelSegments` byte-for-byte (hash-verified across
languages, vitest gate extended), and all fifteen rendered through Voicebox —
never ElevenLabs, founder ruling — with measured chapters. The Daily Bread
mounts the player.

**Seven new module kinds** (redletter, proverb, verse, archive, b365, voices,
question) are built, tested, wired into runner and page, interleaved so games
break up — and BLOCKED ON one founder SQL paste (`APPLY-NOW-2026-08-19b.sql`
widens the kind CHECK; `APPLY-NOW-2026-08-19.sql` enables progress sync).
Until pasted, those sections render nothing and the seed excludes them.

## Platform Contracts

### Desktop

- The contents line runs one row under the masthead; the reading spine sits
  fixed at the left page edge; the gallery leads with the plate at ~58vw
  beside its caption, six thumbs in one row beneath; the lightbox stages the
  plate between paging arrows with the Vasari card below.
- Section heads at `--type-meta`, feature headlines at `--mock-type-3` — one
  rung per semantic level, everywhere on the page.

### Mobile

- Contents line wraps; spine stays (3px, no layout cost); gallery thumbs drop
  to three per row; lightbox arrows hide (tap-through + swipe area remains),
  stage goes single-column; all touch targets ≥ 44px.
- Every band single-column; nothing scrolls the page horizontally — the
  container rule is load-bearing here.

## Build fix — 2026-08-19

`EditionQueueClient`'s `KIND_LABEL` is typed `Record<EditionKind, string>`, and
the seven deterministic kinds this feature added (`redletter`, `proverb`,
`verse`, `archive`, `b365`, `voices`, `question`) never reached it. The map was
committed incomplete, so `next build` failed type-checking on `main` — and only
`next build` caught it: a bare `tsc --noEmit` against a working tree that already
held the fix passed clean, which is how it reached the branch at all.

Labels supplied from the authoring session's own working copy; behaviour
unchanged, the map is a label lookup.

## Bylines link to their author pages (reconciled to git 2026-08-26)

`AuthorColophon` now resolves each credited name through `findAuthorByName`
and links it to `/authors/<slug>`. A byline that matches no author page stays
plain `<strong>` text — an overridden byline is never linked to a page about
someone else.

**Reconciliation note.** This was live in production (the
`author-colophon-name-link` class is present in the served devotional HTML)
but `src/components/devotional/AuthorColophon.tsx` had never been committed.
Its dependencies were verified present in git before committing:
`findAuthorByName` in `src/data/authors.ts`, the `/authors/[slug]` route, and
the `author-colophon-name-link` rule in `globals.css`.
