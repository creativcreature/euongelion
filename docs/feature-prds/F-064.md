## Problem

The results page's guided reveal is dead code (revealedCount inits to 3 — all cards dump at once); result cards look up series data with an AI slug and always render bare (no chips/day-count); the loading skeleton is a 3-up grid while the page is a stacked column; the plan's stored seriesSlug is an AI slug so the resume badge title resolves undefined.

## User Expectation

After sharing something honest, I see ONE recommended direction presented like a considered answer (reveal is a room, not a list — Calm Sleep / Yazio), with the option to explore alternatives one at a time. Cards look complete and intentional. The resume badge names my plan.

## 10/10 Definition

- Progressive reveal live: recommended first with reasoning visible, alternatives on tap.
- Cards render complete text-first (real keywords, real day count, no empty lookups) in light + dark.
- Skeleton is layout-accurate to first paint.
- Resume badge shows a real human title for AI plans.
- Verified end-to-end in the Workers runtime with a real generation.
