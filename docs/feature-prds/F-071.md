## Problem

Search is series-only with no global entry, while structured data advertises a SearchAction with no UI behind it.

## 10/10 Definition

- One global search over series, notes, and clippings, with grouped results and designed empty state; or the advertised SearchAction is removed. Category-standard pattern (Calm / Ten Percent).

## Methodology References

- M00 (canonical IA / navigation UX)

## Device Contracts

### Desktop

- Search from masthead utility; overlay results.

### Mobile

- Search glyph in the top bar (F-063); full-screen sheet.
