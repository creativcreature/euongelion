# F-103: Daily Bread and Today swap, and a shared site bottom

## Metadata

- Feature ID: F-103
- Category: Information architecture
- Owner: founder
- Status: shipped (2026-08-16)
- Decision: SA-059
- Surfaces: `/daily-bread`, `/today`, primary nav, every page's bottom

## Problem

Founder, 2026-08-16:

> "make the menu items smaller on desktop. make the home icon a solid icon and
> not a line. A massive change here. Daily Bread should be the Today page, and
> Today page should be the Daily Bread page. The Daily Edition, is now The Daily
> Bread. All site pages should have the same footer and bottom masthead as the
> home page. The copyright needs to be smaller and all in one line. and the your
> plan continue devotional on home page should be centered. The soul audit input
> box needs to be centered as well."

## Solution

**The two pages swap.** `/daily-bread` now serves **the paper**, whose masthead
reads *The Daily Bread* (it was *The Daily Edition* at `/today`). `/today` now
serves **your reading** — your active plan, your place in it, your next reading.

**SA-033 is superseded in naming only.** Its substance stands: one of these two
pages means *your* devotional and the other means the shared edition. The names
traded places, so any earlier note reading "today means YOUR devotional" is now
inverted.

**Every page ends the same way.** `SiteBottom` — footer columns, EUANGELION
masthead, legal line — extracted from the home page, where it had been inlined
and was simply **absent** from About, Help, Support and the legal pages, which
ended mid-air. 34 files use it now.

**Also:** desktop nav items smaller (0.78em); the home mark is solid rather than
outlined; the copyright is one line of small type; the home resume-plan banner
and the Soul Audit input are centred.

## The swap is by meaning, not by string

This is the part that would break silently. Every reference meaning "take me to
my plan reader" was repointed to `/today`:

- middleware auth matcher
- `/my-devotional` redirect
- soul-audit `current` / `manage` / `select` / `select/status` route payloads
- `onboarding-flow` destination
- `global-search` plan-day hrefs
- `DevotionalLibraryRail` planHref
- the mobile tab
- `LibraryView`, `SeriesActions`, `DevotionalActions` router pushes
- the library page's pointer to the active reading

Anything meaning "the paper" stayed on `/daily-bread`. The `/todays-edition`
alias follows the paper, and gained `force-dynamic` so it answers a real 308
instead of a 36KB meta-refresh page. Nine test files encoded the old contract
and moved with it.

## Two traps worth keeping

**A solid mark beats an outlined one at nav size.** At the ~14px the home icon
actually renders, a hairline outline turns to mud; the filled silhouette reads.

**The copyright kept wrapping at exactly 489px** because `.homepage-bottom-legal p`
(specificity 0-1-1) out-specifies a bare class (0-1-0), so the 92ch paragraph
measure survived every attempt to remove it. The override has to be
`.homepage-bottom-legal p.homepage-bottom-legal-line`.

## Platform Contracts

### Desktop

- Nav: TODAY · DAILY BREAD · SOUL AUDIT · SERIES · LIBRARY · HOW WE WRITE, at
  0.78em, led by a solid home mark whose accessible name is "Home".
- Legal line: one line, 11.5px, uncapped measure.

### Mobile

- Tab bar's first tab is TODAY → `/today`, active for `/today` and
  `/my-devotional`.
- The legal line wraps rather than overflowing — "one line" means one run of
  text, not one that scrolls off a phone.
