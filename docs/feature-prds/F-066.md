## Problem

Momentum is an intentional void (no streaks by conviction) but the absence reads as unfinished: no end-of-session moment, DevotionalMilestoneReveal is orphaned dead code, and there is no gentle signal that showing up mattered.

## Decision (SA-025, founder-locked)

Keep the no-streaks/no-guilt ethos AND add both: (A) a quiet completion beat after a day/plan — a verse, a breath, "come back tomorrow" (Headspace post-session restraint, explicitly NOT Duolingo/Numo confetti); (B) a gentle presence indicator — days you showed up quietly lit, no counts, no broken-streak shame, no red (Open dotted week, Bears Gratitude). Revive DevotionalMilestoneReveal as surface A or delete it and build fresh.

## 10/10 Definition

- Completion beat calm, reduced-motion-safe, dismissible.
- Presence indicator lit/unlit only — zero numbers, zero negative framing on gaps.
- Both respect the brand line ("the app that helps you return without punishing you for leaving").

## Methodology References

- M00 (canonical IA / navigation UX)
- Mobbin anchors: Headspace post-session quote; Open dotted week; Bears Gratitude

## Device Contracts

### Desktop

- Completion beat as an end-of-reading inline moment; presence row on signed-in Today home.

### Mobile

- Same, full-width; presence row on Today + the You tab.
