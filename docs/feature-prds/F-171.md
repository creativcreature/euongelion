## Risks and Rollback

- **The `.ico` must be RGBA.** Writing it as RGB makes Next's decoder throw
  `Format error decoding Ico` on every request — caught during this work.
- OG leads are fetched over HTTP at render time via `NEXT_PUBLIC_APP_URL`. If
  that variable is wrong in an environment, cards degrade to text rather than
  failing, which is the intended failure mode.
- Rollback: restore the previous favicon and drop `imagePath` from the four
  routes. `og-card.tsx` stays backward compatible — the image prop is optional.

## The letter roll was adopted (2026-08-27, F-108 r4)

This feature's intro work landed on `main` on 2026-08-24 and was never merged
into the branch production is deployed from, so it never reached readers. Its
two best ideas have now been adopted into F-108 r4:

1. **The per-letter roll** — one `overflow: hidden` mask per letter with two
   stacked copies, the column travelling exactly one face, staggered left to
   right. This is the reference's signature move (telhaclarke.com.au) and the
   founder's "subtle text rollover". Re-expressed there as script-created Web
   Animations rather than a CSS animation, because a CSS animation on a
   `.press-*` element sorts BELOW the script animations and is the exact cascade
   bug that left F-108's hand-off dead for two releases.
2. **The mode's own colours from frame one** — founder 2026-08-24: "If Light
   Mode, Euangelion should be Blue, if Dark Mode it should be white." This
   feature was right that there had only ever been one version; r4 now paints
   the ground in the page's own ground and the word in the masthead's own
   colour, in both themes, from the first painted frame.

**Not adopted: the hand-off flight.** This implementation kept the wordmark
flying to the masthead. On 2026-08-26 the founder rejected exactly that — "you
see the word twice during the animation. Its already there before animations" —
because the masthead is a permanent element of the page and a second centre-
screen copy is redundant. r4 prints in place instead, and an invariant (INV7)
now holds the wordmark inside the masthead's band for the whole sequence.

One correction worth recording: the roll's mask must be `height: 1lh`, not
`1em`. `1em` is the font size; this masthead runs `line-height: 0.9`, so at the
fitted size an em-tall mask stands 22.7px proud of the real line box.

## Problem

Founder 2026-08-24: "The homepage animation is not working at all the way it
should. This is the intro animation I want [https://telhaclarke.com.au/]. I
need 2 versions - one for Darkmode, one for Light Mode. The Color of the
euangelion needs to match the mode color. If Light Mode, Euangelion should be
Blue, if Dark Mode it should be white. I also want the subtle text rollover."

There was only ever ONE version. The sheet was cobalt in both themes and the
wordmark was knocked out of it, so a light-mode reader watched a cream word on
blue for the entire intro and it became blue only in the final frame as it flew
to the masthead. The mode never had an opening of its own. The nav rollover was
an underline that snapped on instantly with no transition at all.

## Solution

**Two modes, one sequence.** The ground is the mode's own colour (paper
`#f5eee3` light, deep blue `#171b69` dark) and the wordmark is drawn in the
mode's own masthead colour from the first frame (cobalt `#1f2a8d` light, cream
`#efe5d8` dark) — the exact colours `--mock-blue-text` resolves to, so the
flight lands on a masthead already wearing that colour.

**The reference's sequence, in our materials.** Each letter sits in a
one-face-tall overflow mask with a duplicate stacked beneath; the top copy rolls
up and out while the duplicate rolls up into place, staggered per letter
(720ms / 36ms — the same roll:stagger ratio as the reference's 2s / 47.5ms,
against our beat). The ground then leaves on a hard `clip-path` inset rather
than a fade, as the reference opens its page with a clip curtain. The hand-off
to the real masthead is kept and is now pure position and scale: the word needs
no colour change because it was already the masthead's colour.

Implemented in CSS. The reference drives this with GSAP + CustomEase +
SplitText; adding an animation library for one ten-letter wordmark would be a
large dependency for a single sequence, and the roll is a transform on a masked
column either way.

**The rollover.** A 2px rule that WIPES: `scaleX(0)` at rest with its
transform-origin on the right, `scaleX(1)` on hover with the origin flipped
left, 0.7s on `cubic-bezier(.23, 1, .32, 1)` — the reference's own timing. The
flipped origin is the point: the line never rewinds the way it came. Built on
`::before`, never `::after` — EditorialMotionSystem claims `::after` on every
`.mock-paper` link at runtime.

## Platform Contracts

### Desktop

- Intro plays once per session on `/`, both modes, hand-off to the masthead.
- Nav rollover wipes in from the left on hover and focus-visible.

### Mobile

- Same sequence; the wordmark is `clamp()`-sized so the widest frame fits.
- The rollover is a hover/focus affordance and is inert on touch, as before.
