## Device Contracts

### Desktop

- Print rail measures once per frame during scroll, not once per scroll event.
- Nav scroll-direction cancels its pending frame on unmount.
- Daily Bread renders the lead plate only when a source actually resolves.

### Mobile

- Same guarantees. The print rail's coalescing matters most on touch, where
  momentum scrolling emits the densest event stream and the per-event
  `getBoundingClientRect()` walk was heaviest.
