# F-116: The Soul Audit input sat 34px off centre

## Metadata

- Feature ID: F-116
- Category: Soul Audit
- Owner: founder
- Status: shipped (2026-08-16)
- Decision: SA-072
- Surfaces: `/soul-audit`

## Problem

> "soul audit input box needs to be centered."

Measured on the live page at 1680px: the textarea sat **483px from the left and
517px from the right** — 34px off centre.

## Cause

Every ancestor was already centred correctly. Walking the chain, each one
reported an identical left and right gap:

| Element                     | Width   | Off by  |
| --------------------------- | ------- | ------- |
| `section.shell-content-pad` | 1629    | 0       |
| `div.w-full.max-w-2xl`      | 714     | 0       |
| `div.fade-in-section`       | 714     | 0       |
| **`textarea`**              | **680** | **−34** |

The field carries `vw-body-lg`, a reading-measure utility that sets
`max-width: 680px`. Inside a 714px column that leaves 34px of slack — and
because a `textarea` is `display: inline-block` and the column aligns to
`start`, all of that slack collected on the right.

So the box was narrower than its container and pinned to the left edge of it.

## Fix

`block` + `mx-auto` on the textarea. That centres the field in its column
**without touching the measure** — 680px is a good line length for a text field
and is left exactly as it was.

## Why it wasn't obvious

The container was centred, the page was centred, and nothing overflowed. Only
the element that actually renders the box was off, and it was off by an amount
that reads as "slightly wrong" rather than plainly broken. **When something
looks off centre, measure the element itself, not its container** — a perfectly
centred parent tells you nothing about a child that is narrower than it.

## Contracts

### Desktop

- The textarea's left and right gaps are equal at every viewport ≥ 700px.
- The 680px reading measure is preserved.

### Mobile

- Below 680px the field is full-width, so `mx-auto` is inert and nothing
  changes.

## Acceptance criteria

- [x] Textarea left gap equals right gap (±1px) at 1680px
- [x] `max-width: 680px` unchanged
- [x] No other off-centre form control on `/soul-audit` or `/`
- [x] No horizontal overflow at 390px
