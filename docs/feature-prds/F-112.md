## Problem

> "im honestly not a fan of this now that I see it close to implimented. i think
> the one I made for my personal website is a little better… I want the same
> card size, boarder and the columns also have a scroll movement."

Reference changed from nicolaromei.com to the founder's own gallery.

## What was measured

`creativcreature.wokegod.world/gallery`, read off the live page rather than
described: **80×80 cards on an 88px pitch, `object-fit: cover`, 4px radius**,
dense uniform grid, no captions over the image.

## What Flow takes, and what it changes

**Takes:** uniform square cards, cover-cropped and never stretched, a soft 4px
radius with a hairline border, dealt into columns.

**Changes, on instruction:**

- *"I only need the two largest size levels… not the small sizwe… but larger
  than the reference"* — exactly **two** steps, 340px and 250px, both far above
  the reference's 80px, switchable from a control above the board.
- *"the type should uppear bellow image, not on top"* — the caption sits under
  the plate, which also means it never covers artwork.
- *"the columns also have a scroll movement"* — the board is a row of columns
  four cards deep running sideways, and each column is nudged vertically as the
  board travels, alternating direction at rates that don't divide evenly so no
  two neighbours move together. **Capped at 26px**: a column must never drift
  far enough to put a card out of reach.

## Contract

- The wheel listener is attached **natively with `{ passive: false }`**. React
  registers wheel listeners as passive, so `preventDefault` inside a React
  `onWheel` fails and logs an error on **every notch** — 199 in one session.
- Plates load **eager** inside the scroll container (see F-110).
- Column drift is disabled entirely under `prefers-reduced-motion`.

## The lesson

Four rebuilds of this one view in a day. Each time the cause was the same: I
designed from a description instead of measuring the reference. The founder had
to say *"Please look at the dang site. ACTUALLY LOOK AT IT"* before I
screenshotted it. **Measure the reference first.**

## Platform Contracts

### Desktop

- Frame ≤66vh inside the newspaper border; scrolls both axes.
- Wheel travels the board sideways and releases to the page at either end.
- Drag pans both axes at 1:1.

### Mobile

- Frame ≤60vh; native scrolling owns both axes, drag handlers bail on touch.
- Size control and captions unchanged.
