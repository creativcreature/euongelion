## Problem

The founder's brief on the prior homepage: _"the rest of the page isnt
telling the stroy of the site fully, nor is it set up to show how the user's
problems get solved, or why the user would want to be here."_ The diagnosis
(recorded in the Three Homepages proposal and re-measured against last-30-days
research): the page asked for commitment before it earned it, the Soul Audit —
the one thing no competitor has — sat tenth, reassurance was split across two
strips seven blocks apart, and the scale of the library was never stated.
The founder's final rulings: everything below the header may change; **the
Word leads**; the opening block is **the verse of the day, pulled from the
Daily Bread, which changes daily**.

## Solution

**The Word of the Day opens the page.** `getWordOfTheDay()` resolves the
Daily Bread edition's daily proverb row (BSB verbatim) for
`effectiveEditionDate()`; the edition's `verse` kind is the weekly memory
verse (repeats seven days by design) and so cannot serve a daily block —
swapping later is a one-line kind change. `page.tsx` becomes a thin ISR
server wrapper (`revalidate = 3600`, the /daily-bread cadence) around the
client body, renamed `HomeClient`. A missing row renders a visibly
unavailable block; the page survives (Rule 1).

**The research-backed order below it:** Soul Audit second (condition line
above the question), the Grace Line ("FREE. NO ACCOUNT. NO ADS. NO STREAKS.
NOTHING TO FALL BEHIND ON." — each clause inverting a documented category
complaint), the featured reading with a daily caption and the audio callout
beneath it, the computed scale line, series rail, shortened how-it-works,
exactly one closing action (resume-aware), and the FAQ reordered so sign-up
and missed-day lead.

**Deleted (founder-authorized):** the action ladder, both trust rows, "What
is this place?", and the closing CTA's competing secondary link.

**Copy** drafted by the DEVOTIONAL-WRITER (three options per slot,
recommendations adopted; all alternates preserved in the session report for
morning swaps). Reorder, not restyle: existing components and classes carry
the change (SA-037 precedent).

## Platform Contracts

### Desktop

- Block order below the header: Word → Soul Audit → Grace Line → featured
  reading (+ caption) → audio callout → scale line → series rail →
  how-it-works → one action → FAQ.
- The Word renders as centered display serif with the reference as a quiet
  label; the two strips share the trust-row visual voice.

### Mobile

- Same order; the Word block's type scales via clamp() and the strips wrap.
- The one closing action remains a single full-width button; no competing
  links at any viewport.

## Acceptance

- `__tests__/homepage-word-first-contract.test.ts` (watched red first) pins:
  the resolver returns the daily proverb and throws on a missing row; the
  page split (server wrapper + client body); the block order; the deletions;
  the FAQ order; the computed scale line.
- Full gates green; production build green; smoke test renders HomeClient
  with a stub Word.
- Workers preview: served HTML contains the Word block (or its visible
  unavailable state), the Grace Line, exactly one closing action, and no
  ladder/trust-row markup; verified again on production after deploy.
- Homepage responds with hourly revalidation (ISR) rather than the year-long
  static cache.
