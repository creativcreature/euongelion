## Problem

Returning users land on a marketing page doing a returning-user's job. There is no greeting + continue + one-recommendation home (Calm/Headspace model).

## 10/10 Definition

- A returning user with an active plan lands on (or is one tap from) a Today surface: quiet greeting, continue-reading card, one recommendation, presence row (F-066) — not the marketing pitch.
- Anonymous first-time visitors still get the marketing landing.

- Today is the default tab (F-063); greeting + continue card above the fold.
