## Shipped — backlog #15

[Matter](https://mobbin.com/screens/647cefed-7ed5-407b-9c6d-49505138c1a9)
exposes Spacing and Width beside Font and Size. For long-form scripture those
two do more for legibility than typeface choice, and neither was reachable here.

The sheet now carries **TEXT SIZE · LINE SPACING · LINE WIDTH**, all three in the
same stepper rhythm the reader already knew.

| Control      | Steps                    | Effect                                 |
| ------------ | ------------------------ | -------------------------------------- |
| LINE SPACING | Tight · Standard · Open  | `line-height` 1.5 / inherited / 1.95   |
| LINE WIDTH   | Narrow · Standard · Wide | `--measure-reading` 58ch / 68ch / 78ch |

Verified live: measure moved 68ch → 78ch and line-height 25.5px → 33.15px from
the sheet, with `data-reading-measure` / `data-reading-leading` landing on
`<html>`.

### How it is wired, and why that way

Both ride `<html>` data attributes — the same channel `data-text-scale` already
uses via `providers.tsx` — so every reading preference lives in one place rather
than three mechanisms.

**Leading is scoped to the reading flow, not global.** A global `line-height`
would drag captions, labels and the masthead with it. **Measure overrides
`--measure-reading`**, the token the reader column and `PullQuote` already
share, so the whole column moves coherently instead of one element at a time.

Named steps rather than raw sliders, matching how this reader already handles
theme and text size: a reader picks a feel, not a number.

## Backlog #16 was already done

"Offer more than two reading grounds" is **already shipped** — the sheet has
carried four named themes since F-067: Ink, Parchment, Vellum, Night. Recorded
here so it is not built twice; no code changed for it.

## A test that had to change

`reader-theme-control.test.tsx` asserted `getByText('Standard')`. All three
steppers now read "Standard" at their defaults, so that query is ambiguous by
design rather than by bug. It is scoped to the TEXT SIZE group with `within`.
