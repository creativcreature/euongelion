# F-162: A reading registers itself, so it can be paused from anywhere

## Metadata

- Feature ID: F-162
- Category: Reading surfaces
- Owner: founder
- Status: shipped (2026-08-19)
- Decision: SA-117
- Surfaces: `src/components/NarrationPlayer.tsx`, `src/components/audio/GlobalAudioHost.tsx`

## Problem

Founder, from live use:

> "the site should not be autoplaying.... and ther is no way to turn pause right
> now. the player didnt even detect the audio was playing."

Reproduced in Chrome against production. Press play in a reading, navigate to
`/series`, and: `paused: false`, `currentTime: 30.1` — still sounding — with
`pauseControls: []`. **No way to stop it anywhere on the site.**

Two distinct causes, both mine:

1. **The reader told the store nothing.** It drove the shared element directly.
   The drawer handle carries the only pause control outside the reader's own
   panel, and it appears only when the store holds an item — so an empty queue
   meant no handle, no control, audio sounding on.
2. **The stale shell.** Readers still on a cached build had the pre-SA-115
   reader, which rendered its own `<audio>` alongside the host's. Two engines:
   the visible controls drove one while the other sounded, which is exactly
   "the player didn't detect the audio was playing".

It reads as autoplay because audio continues across navigation — which is the
intended feature — while nothing on screen admits it is playing.

## Solution

**A reading registers itself on play.** `NarrationPlayer`'s `play` listener puts
the reading into the audio store as a single-item queue, so the drawer handle
appears and carries a pause control on every route.

**Only when it is not already the cursor.** Pressing play inside a queue must
not collapse that queue to one item, so the registration is skipped when this
reading is already what the store is pointing at.

**The host adopts an already-loaded src.** Registering makes the host's loader
see a new item; without a guard it would reassign `src` and `load()` on an
element mid-playback, restarting the reading under the listener. It now records
the src and returns when the element already carries it.

## Platform Contracts

### Desktop

- Playing a reading, then navigating anywhere, leaves a visible pause control.
- Playing inside a queue does not discard the queue.

### Mobile

- Same, via the tucked handle above the tab bar.
