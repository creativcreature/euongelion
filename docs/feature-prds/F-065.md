## Problem

Anonymous users (the majority) get no first-run at all; the real 5-step onboarding is double-gated behind auth AND first-session; GuestSignupGate (guest capture for Sabbath/theme/text-size) is fully built but imported nowhere; magic-link sign-in dead-ends at "check your email" with no in-app code entry.

## User Expectation

- First visit: an optional, dismissible introduction (value + one personalization tap + gentle account offer) — never a wall.
- Sign-in: I can type the emailed code without leaving the app (Linear model).
- My guest preferences follow me into an account if I create one.

## 10/10 Definition

- Anonymous first-run present + dismissible; guest personalization wired (GuestSignupGate) or removed; magic-link code entry beside the link; one coherent save gate (no post-tap 401 surprises).

## Methodology References

- M00 (canonical IA / navigation UX)
- Mobbin anchors: Linear (code entry), Wanderlog (bookends), Mindvalley (fork), Finch (gentle opt-in)

## Device Contracts

### Desktop

- First-run as a centered dismissible sequence; code entry inline on /sign-in.

### Mobile

- Same flows, full-width, safe-area aware; keyboard-friendly code input.
