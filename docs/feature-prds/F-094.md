## The organising idea

Ten arbitrary CSS grids would be ten arbitrary CSS grids. The founder's own
words for this page are "a library of magazines" and "each devotional is a
newspaper on the rack", so each view is a **real form of displaying print** and
takes its proportions and furniture from that form:

| View | Reference |
| --- | --- |
| Feature | *Monocle* front-of-book — one lead plate, varied tiles |
| Rack | a kiosk rail — folded papers overlapping, mastheads out |
| Covers | a Phaidon monograph plate wall |
| Spines | a shelf — titles up the spine, width encodes length |
| List | a stock list / departure board |
| Index | back-of-book index with dot leaders |
| Contact | a Magnum contact sheet, frames numbered |
| Mosaic | Richter's *Atlas* wall |
| Broadsheet | a newspaper page — lede, column rules, listings |
| Issues | an issue chronology, numbered by release |

## Fixes asked for, and what changed

| Ask | Change |
| --- | --- |
| Bento title hierarchy | The gold uppercase kicker **above** the title is gone — it was the brightest thing on the tile and the least important. Tile = plate + title, length quiet beneath. |
| Bento image proportions | Rows 150px → 210px, `grid-auto-flow: dense` so spans leave no holes. |
| Library columns | Eight → four (`covers`), plates at 3:4. |
| List shows category | Pathway column removed; three tracks — title, question, length. |
| Newspaper rack | `RACK`, with rails, fixed leans, fold shading and a pull-out hover. |
| Ten layouts, icon-toggled | Ten, each with a glyph that is a miniature of its own layout. |

## Design decisions worth keeping

- **Numbers must mean something.** Decorative `01 / 02 / 03` is the generic
  default. Contact numbers frames by position in the *current sort*; Issues
  numbers by release order; spine **width** encodes length.
- **`--mock-ink` inverts per theme and must never ground `--plate-ink` type.**
  In dark mode `--mock-ink` *is* cream, which rendered the spines
  cream-on-cream. `--plate-ground` (`#131b40`) is fixed in both themes. Third
  variant of the trap behind SA-044 and SA-047.
- **Every state is designed.** Search hands the page over; an empty result names
  the query and offers five seeds that actually return something; a returning
  reader gets "Day n of m" and a rail. No pre-hydration spinner — the catalog is
  static and server-rendered, so only progress fills in.
- **The chosen layout persists** per device. With ten, resetting to Feature every
  visit would be a small insult.

## Platform Contracts

### Desktop

- Bento is four columns of 210px rows with `grid-auto-flow: dense`; the lead
  spans 2×2. Covers is four columns at 3:4. Broadsheet and Mosaic set four CSS
  columns; Index sets two. Rack lays six papers per rail with a −7px overlap so
  only the edges tuck, never the standfirst.
- Spines scroll horizontally on a 320px shelf; width is `30 + days × 3`px
  clamped to 34–74 so a 365-day plan does not become a wall.
- The switcher is a hairline-divided case of seven icon+label controls, CENTRED,
  with sort centred on its own row beneath (SA-050). The active control is inked
  solid.
- The resume line sits above the search: one centred row, meta-sized and muted,
  rendering nothing when no plan is active.

### Mobile

- Tested at 375px and 390px. Bento drops to two columns at 900px and 150px rows
  at 640px, where `tall` collapses to a single row. Covers goes to two columns,
  Broadsheet to one, Rack to two papers per row with the overlap removed.
- Under 640px the switcher shows **icons only** (labels hidden) and centres, so
  ten controls still fit one line without horizontal scroll.
- List drops to a stacked two-track row with the question on its own line;
  Issues hides its right-hand meta column.
- `prefers-reduced-motion` disables plate zoom, paper lean and spine lift.

## Risks

| Risk | Mitigation |
| --- | --- |
| Seven layouts is six chances to hide a series | Coverage asserted against `ALL_SERIES_ORDER` in every view, in test. |
| A rack of tilted papers reads as noise | Leans are fixed per position, never random, so the shelf is identical every render. |
| Seven icons on small screens | Labels drop below 640px; icons stay legible at 20px and the row stays centred. |
