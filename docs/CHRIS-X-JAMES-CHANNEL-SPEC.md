are awareness and funnel, never the growth engine. Any plan that leads with Shorts fails
this gate by construction.

## 5. Production system

### 5.1 Capture rig — designed against the real constraint

The blocker is **living-space intrusion**, not gear or skill (THC set precedent). Design
goal: a corner that is never struck and never in the way.

- iPhone, locked tripod, marked floor position and camera height. Never re-framed.
- Lav or short shotgun mic. **Audio is the one place cheap hurts.**
- One fixed light, or one window at a fixed hour.
- Outline on a second screen at eye line. **No memorisation, no full script.**
- Batch: one setup, one wardrobe, 3–6 pieces per session. ~1 shoot day / fortnight at 2×/wk.
- Anamorphic lens: **declined.** Adds a per-shoot decision for negligible gain.

### 5.2 Render stack — verified working 2026-08-20

12 skills incl. `remotion-captions`, `remotion-render`, `remotion-multimedia`.

Tailwind v4. `src/Short.tsx` is one prop-driven composition reading chapter in/out points
from `audio-manifest.json`.

## 6. Cadence and acceptance criteria

**Cadence: 2 long-form / week.** Derivation:

```
4,000 h = 240,000 min
12-min video @ ~35% retention ≈ 4.2 min AVD
240,000 / 4.2 ≈ 57,000 views over 23 weeks ≈ 2,500 views/week
@ 2/wk → ~46 videos → ~1,240 views each
```

1/week fails this on any realistic retention assumption. Stated plainly: **the two-month
target the founder asked for requires a breakout, not a system.** Build for six.

| Gate               | Criterion                                                        |
| ------------------ | ---------------------------------------------------------------- |
| **G-A** rig        | One take recorded start-to-finish with zero setup decisions      |
| **G-B** format     | First 3 videos cut; founder approves the auto-cut first pass     |
| **G-C** door       | Every published title maps to a real observed search query       |
| **G-D** safe area  | Every vertical cut passes `SAFE`; no type below y=1436           |
| **G-E** disclosure | Cloned-voice pieces carry disclosure in description AND metadata |
| **G-F** pace       | 2 long-form/week sustained 4 consecutive weeks                   |
| **G-G** YPP        | 1,000 subs + 4,000 h **before 2027-02-01**                       |
